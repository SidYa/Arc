# Arc — мінімалістичний архіватор

Десктопний архіватор для Windows (Linux — пізніше). Еталон за можливостями — 7-Zip,
але з сучасним мінімалістичним інтерфейсом. Спілкування з користувачем — українською,
коментарі в коді та назви — англійською.

## Стек
- **Бекенд:** Rust, Tauri 2 (`app/src-tauri`).
- **Фронтенд:** Svelte 5 (руни) + SvelteKit `adapter-static` (SPA) + Vite, TypeScript, іконки `@lucide/svelte` (`app/src`).
- **Переклади:** `lang/en.json`, `lang/uk.json` (ключ → текст, `{}` — плейсхолдери), спільні для Rust і фронтенду.

## Еталон інтерфейсу — Tormin (`D:\GIT\Soft\Tormin`)
Інтерфейс, токени і компоненти беремо з Tormin і тримаємо в тому ж стилі:
- вікно без системної рамки (`decorations(false)`), Mica на Windows 11, власний заголовок `TitleBar.svelte`;
- **усі кнопки дій — у верхній панелі (заголовку вікна)**, порожнє місце тягне вікно (`data-tauri-drag-region`);
- дизайн-токени в `app.css` (`--bg`, `--surface*`, `--accent*`, `--radius`…), темна тема за замовчуванням, `html[data-theme="light"]`;
- **акцентні кольори:** пресети purple/green/orange/blue + власний `#rrggbb` (через `fitAccent()` в `accent.ts`, що підтягує контраст) + «system» (акцент Windows із реєстру DWM);
- спільні компоненти: `Menu`, `Modal`, `Select`, `Dialogs` (черга діалогів у `store.svelte.ts` через `openDialog(kind, props)`), `Settings`.
Перш ніж робити новий елемент UI, подивись, як подібне зроблено в Tormin.

## Функціональність
| Формат | Створення | Розпакування | Пароль |
|---|---|---|---|
| .zip | `zip` | `zip` | AES-256 (читання також ZipCrypto) |
| .7z | `sevenz-rust2` (LZMA2) | `sevenz-rust2` | AES-256, опційно шифрування назв |
| .tar.gz / .tgz | `tar` + `flate2` (zlib-rs) | те саме | — (формат не підтримує) |
| .tar.xz | `tar` + `liblzma` (static, parallel) | те саме | — |
| .rar | — (ліцензія UnRAR забороняє) | `unrar` | так |

- Головне вікно — **браузер архіву** як у 7-Zip: навігація по папках усередині архіву, відкриття окремого файлу подвійним кліком без розпакування всього архіву (файл розпаковується в `%TEMP%\Arc\…` і відкривається програмою за замовчуванням), розпакування вибраних елементів.
- Drag-and-Drop: архів → відкрити; інші файли/папки → діалог створення архіву.
- Операції (jobs) виконуються у фонових потоках; прогрес надсилається подією не частіше ~10 разів/с; кожну можна скасувати.
- Імена в старих ZIP без прапорця UTF-8: системна OEM-сторінка, якщо вона кирилична (866/1125); інакше евристика — серія ≥3 байтів у кириличних діапазонах CP866 або кирилична локаль → CP866, а байти 0xF6–0xF9 → CP1125 (українська Windows); інакше CP437. У користувача англійська Windows (OEMCP=437), тому на системну сторінку покладатися не можна.
- Обов'язковий захист від zip-slip: імена записів проходять через безпечне з'єднання шляхів (без `..`, коренів, дисків).
- Помилки пароля передаються фронтенду кодами `password_required` / `wrong_password` — фронтенд питає пароль і повторює операцію.

## Контекстне меню Explorer (як у 7-Zip)
Реєстр `HKCU\Software\Classes` (без прав адміністратора), каскадне меню «Arc»:
Архівувати · Запаролити · Розархівувати · Розархівувати в папку.
- У Windows 11 воно видно в «Показати більше параметрів» — це свідоме рішення (верхнє меню потребує підписаного MSIX + COM `IExplorerCommand`, відкладено).
- Пункти розпакування показуються лише для архівних розширень (`AppliesTo`), `MultiSelectModel=Player`.
- При виборі кількох файлів Explorer запускає процес на кожен файл: `tauri-plugin-single-instance` пересилає аргументи в перший екземпляр, а той збирає їх ~450 мс в одну пакетну операцію (одна архівація всіх файлів; «в папку» — кожен архів у свою папку з назвою архіву).
- «В папку» — **завжди** папка з назвою архіву (вимога користувача); подвійна вкладеність прибирається лише коли всередині одна папка з тією ж назвою (`foo.zip` з `foo\` → `foo\…`).
- Запуск із меню (будь-яка дія, крім open) = task mode: після успішного завершення всіх операцій вікно закривається само; при помилці лишається відкритим.
- Пункти меню реєструються як `*\shell\Arc` + `Directory\shell\Arc` (пакування) і `SystemFileAssociations\.<ext>\shell\Arc` (повне меню): однакове ім'я дієслова, тож Explorer показує для архівів лише специфічне.
- Аргументи командного рядка: `--add`, `--add-password`, `--extract-here`, `--extract-folder`, без ключа — відкрити архів.
- Ключі реєструються при запуску (якщо увімкнено в налаштуваннях) і видаляються NSIS-хуком при деінсталяції.

## Структура
```
lang/                 переклади en/uk
app/src/              фронтенд (routes/+page.svelte, lib/api.ts, lib/store.svelte.ts, lib/components/*)
app/src-tauri/src/    lib.rs (команди, стан, single-instance), config.rs, jobs.rs,
                      archive/ (mod.rs — спільні типи і детект формату; zip.rs, sevenz.rs, tar.rs, rar.rs),
                      shell.rs (контекстне меню, системний акцент)
```

## Збірка та перевірка
- Розробка: `app\dev.ps1` (або `npm run tauri dev` у `app`), інсталятор: `app\dev.ps1 -Build` (NSIS).
- Із Bash-інструменту `npm run tauri dev` не бачить cargo: запускати з PowerShell з `$env:Path = "$env:USERPROFILE\.cargo\bin;$env:Path"` і `cmd /c "npm run tauri dev > log 2>&1"` (dev.ps1 з перенаправленням падає через `ErrorActionPreference=Stop` на stderr npm).
- UI перевіряється знімками вікна (скрипти shot/click/type у scratchpad). У системі не англійська розкладка: `SendKeys` вводить сміття — текст вводити через буфер обміну + `keybd_event` (VK-коди).
- Гарячі клавіші WebView2 (пошук F3/Ctrl+F, друк тощо) блокуються в `+page.svelte` (`blockBrowserKeys`, capture-фаза) — у Tauri немає прапорця для цього.
- Перевірки: `cargo check` / `cargo test` у `app/src-tauri`, `npm run check` у `app`.
- `unrar` і `liblzma` компілюють C/C++ — потрібен MSVC (є).
- Конфіг користувача: `%APPDATA%\Arc\config.json`, лог: `%LOCALAPPDATA%\Arc\arc.log`.

## Відкладено / наступні етапи
- Збірка для Linux (контекстне меню — Nautilus/Dolphin).
- Верхнє контекстне меню Windows 11 (MSIX + підпис).
- Додавання/видалення файлів в існуючому архіві, перетягування з архіву в Explorer.
