# Arc

A minimalist archiver

- Create and extract **ZIP**, **7Z**, **TAR.GZ / TGZ**, **TAR.XZ**; extract **RAR**
- Browse an archive like a folder and open single files without extracting everything
- Password protection: AES-256 for ZIP and 7Z, optionally with encrypted file names (7Z)
- Explorer context menu like 7-Zip: *Add to archive*, *Add with password*, *Extract* (as is), *Extract to "name\"*, *Extract to…* (choose a folder) — several selected archives go into one folder each
- Uses every processor core: ZIP, TAR.GZ, TAR.XZ and 7Z are compressed in parallel, also a single large file
- Drag & drop, progress with speed and time left, cancel at any moment
